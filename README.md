# 👻 Ghost सुरक्षा मोड्युल
**PowerShell आधारित Windows र Azure सुरक्षा सुदृढीकरण उपकरण**

> **Windows endpoints र Azure वातावरणहरूको लागि सक्रिय सुरक्षा सुदृढीकरण।** Ghost ले PowerShell आधारित सुदृढीकरण प्रकार्यहरू प्रदान गर्छ जसले अनावश्यक सेवाहरू र प्रोटोकलहरू असक्षम गरेर सामान्य आक्रमण भेक्टरहरू कम गर्न मद्दत गर्न सक्छ।

## ⚠️ महत्वपूर्ण चेतावनीहरू

**परीक्षण आवश्यक**: सधैं पहिले गैर-उत्पादन वातावरणहरूमा Ghost परीक्षण गर्नुहोस्। सेवाहरू असक्षम पार्दा वैध व्यापार कार्यहरूलाई असर गर्न सक्छ।

**कुनै ग्यारेन्टी छैन**: Ghost ले सामान्य आक्रमण भेक्टरहरूलाई लक्षित गरे तापनि, कुनै पनि सुरक्षा उपकरणले सबै आक्रमणहरू रोक्न सक्दैन। यो व्यापक सुरक्षा रणनीतिमा एक घटक हो।

**परिचालन प्रभाव**: केही प्रकार्यहरूले सिस्टम कार्यक्षमतालाई असर गर्न सक्छ। तैनाती अघि प्रत्येक सेटिङलाई सावधानीपूर्वक समीक्षा गर्नुहोस्।

**व्यावसायिक मूल्याङ्कन**: उत्पादन वातावरणहरूको लागि, सेटिङहरू तपाईंको संगठनको आवश्यकताहरूसँग मिल्छ भनेर सुनिश्चित गर्न सुरक्षा विशेषज्ञहरूसँग सल्लाह गर्नुहोस्।

## 📊 सुरक्षा परिदृश्य

Ransomware हानि **2025 मा $57 बिलियन** पुग्यो, अनुसन्धानले देखाउँछ कि धेरै सफल आक्रमणहरूले आधारभूत Windows सेवाहरू र गलत कन्फिगरेसनहरूको शोषण गर्छन्। सामान्य आक्रमण भेक्टरहरूमा समावेश छन्:

- **90% ransomware घटनाहरू** RDP शोषण समावेश गर्छन्
- **SMBv1 कमजोरीहरू** WannaCry र NotPetya जस्ता आक्रमणहरूलाई सक्षम पार्यो
- **कागजात म्याक्रोहरू** मालवेयर डेलिभरीको प्राथमिक विधि बनिरहन्छ
- **USB आधारित आक्रमणहरू** एयर-ग्याप नेटवर्कहरूलाई लक्षित गर्न जारी राख्छ
- **PowerShell दुरुपयोग** हालका वर्षहरूमा महत्वपूर्ण रूपमा बढेको छ

## 🛡️ Ghost सुरक्षा प्रकार्यहरू

Ghost ले **16 Windows सुदृढीकरण प्रकार्यहरू** र **Azure सुरक्षा एकीकरण** प्रदान गर्छ:

### Windows Endpoint सुदृढीकरण

| प्रकार्य | उद्देश्य | विचारहरू |
|----------|---------|----------------|
| `Set-RDP` | Remote Desktop पहुँच व्यवस्थापन गर्छ | टाढाको प्रशासनमा असर गर्न सक्छ |
| `Set-SMBv1` | पुरानो SMB प्रोटोकल नियन्त्रण गर्छ | धेरै पुराना सिस्टमहरूको लागि आवश्यक |
| `Set-AutoRun` | AutoPlay/AutoRun नियन्त्रण गर्छ | प्रयोगकर्ता सुविधालाई असर गर्न सक्छ |
| `Set-USBStorage` | USB भण्डारण उपकरणहरू सीमित गर्छ | वैध USB प्रयोगमा असर गर्न सक्छ |
| `Set-Macros` | Office म्याक्रो कार्यान्वयन नियन्त्रण गर्छ | म्याक्रो-सक्षम कागजातहरूमा असर गर्न सक्छ |
| `Set-PSRemoting` | PowerShell रिमोटिङ व्यवस्थापन गर्छ | टाढाको व्यवस्थापनमा असर गर्न सक्छ |
| `Set-WinRM` | Windows Remote Management नियन्त्रण गर्छ | टाढाको प्रशासनमा असर गर्न सक्छ |
| `Set-LLMNR` | नाम समाधान प्रोटोकल व्यवस्थापन गर्छ | सामान्यतया असक्षम पार्न सुरक्षित |
| `Set-NetBIOS` | TCP/IP मा NetBIOS नियन्त्रण गर्छ | पुराना एप्लिकेसनहरूमा असर गर्न सक्छ |
| `Set-AdminShares` | प्रशासनिक साझेदारी व्यवस्थापन गर्छ | टाढाको फाइल पहुँचमा असर गर्न सक्छ |
| `Set-Telemetry` | डाटा सङ्कलन नियन्त्रण गर्छ | निदान क्षमताहरूमा असर गर्न सक्छ |
| `Set-GuestAccount` | अतिथि खाता व्यवस्थापन गर्छ | सामान्यतया असक्षम पार्न सुरक्षित |
| `Set-ICMP` | ping प्रतिक्रियाहरू नियन्त्रण गर्छ | नेटवर्क निदानमा असर गर्न सक्छ |
| `Set-RemoteAssistance` | Remote Assistance व्यवस्थापन गर्छ | help desk सञ्चालनमा असर गर्न सक्छ |
| `Set-NetworkDiscovery` | नेटवर्क खोज नियन्त्रण गर्छ | नेटवर्क ब्राउजिङमा असर गर्न सक्छ |
| `Set-Firewall` | Windows Firewall व्यवस्थापन गर्छ | नेटवर्क सुरक्षाको लागि महत्वपूर्ण |

### Azure Cloud सुरक्षा

| प्रकार्य | उद्देश्य | आवश्यकताहरू |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | आधारभूत Azure AD सुरक्षा सक्षम गर्छ | Microsoft Graph अनुमतिहरू |

| `Set-AzurePrivilegedUsers` | विशेषाधिकार प्राप्त खाताहरू अडिट गर्छ | Global Admin अनुमतिहरू |

### Enterprise तैनाती विकल्पहरू

| **प्रत्यक्ष कार्यान्वयन** | परीक्षण, सानो वातावरण | स्थानीय admin अधिकारहरू |

## 🔍 प्रकार्य विवरणहरू

### मुख्य सुदृढीकरण प्रकार्यहरू

#### नेटवर्क सेवाहरू
- **RDP**: टाढाको डेस्कटप पहुँच ब्लक गर्छ वा पोर्ट अनियमित बनाउँछ
- **SMBv1**: पुरानो फाइल साझेदारी प्रोटोकल असक्षम पार्छ
- **ICMP**: जासूसीको लागि ping प्रतिक्रियाहरू रोक्छ
- **LLMNR/NetBIOS**: पुराना नाम समाधान प्रोटोकलहरू ब्लक गर्छ

#### एप्लिकेसन सुरक्षा
- **म्याक्रोहरू**: Office एप्लिकेसनहरूमा म्याक्रो कार्यान्वयन असक्षम पार्छ
- **AutoRun**: हटाउन मिल्ने मिडियाबाट स्वचालित कार्यान्वयन रोक्छ

#### टाढाको व्यवस्थापन
- **PSRemoting**: PowerShell टाढाका सत्रहरू असक्षम पार्छ
- **WinRM**: Windows Remote Management रोक्छ
- **Remote Assistance**: टाढाको सहायता जडानहरू ब्लक गर्छ

#### पहुँच नियन्त्रण
- **Admin Shares**: C$, ADMIN$ साझेदारीहरू असक्षम पार्छ
- **Guest Account**: अतिथि खाता पहुँच असक्षम पार्छ
- **USB Storage**: USB उपकरण प्रयोग सीमित गर्छ

### Azure एकीकरण
```powershell
# Azure tenant मा जडान गर्नुहोस्
Connect-AzureGhost -Interactive

# सुरक्षा पूर्वनिर्धारितहरू सक्षम गर्नुहोस्
Set-AzureSecurityDefaults -Enable

# सशर्त पहुँच कन्फिगर गर्नुहोस्
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# विशेषाधिकार प्राप्त प्रयोगकर्ताहरू अडिट गर्नुहोस्
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune एकीकरण (v2 मा नयाँ)
```powershell
# Intune मा जडान गर्नुहोस्
Connect-IntuneGhost -Interactive

# Intune नीतिहरूमार्फत तैनात गर्नुहोस्
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ महत्वपूर्ण विचारहरू

### परीक्षण आवश्यकताहरू
- **प्रयोगशाला वातावरण**: पहिले सबै सेटिङहरू अलग वातावरणमा परीक्षण गर्नुहोस्
- **चरणबद्ध तैनाती**: समस्याहरू पहिचान गर्न बिस्तारै रोलआउट गर्नुहोस्
- **फिर्ता योजना**: आवश्यक भएमा परिवर्तनहरू उल्टाउन सक्छ भनेर सुनिश्चित गर्नुहोस्
- **कागजात**: तपाईंको वातावरणको लागि कुन सेटिङहरू काम गर्छ रेकर्ड गर्नुहोस्

### सम्भावित प्रभाव
- **प्रयोगकर्ता उत्पादकता**: केही सेटिङहरूले दैनिक कार्यप्रवाहमा असर गर्न सक्छ
- **पुराना एप्लिकेसनहरू**: पुराना सिस्टमहरूलाई विशिष्ट प्रोटोकलहरू आवश्यक पर्न सक्छ
- **टाढाको पहुँच**: वैध टाढाको प्रशासनमा प्रभाव विचार गर्नुहोस्
- **व्यापार प्रक्रियाहरू**: सेटिङहरूले महत्वपूर्ण प्रकार्यहरू तोडदैन भनेर प्रमाणित गर्नुहोस्

### सुरक्षा सीमाहरू
- **गहिरो रक्षा**: Ghost सुरक्षाको एक तह हो, पूर्ण समाधान होइन
- **निरन्तर व्यवस्थापन**: सुरक्षालाई निरन्तर निगरानी र अद्यावधिक चाहिन्छ
- **प्रयोगकर्ता तालिम**: प्राविधिक नियन्त्रणलाई सुरक्षा जागरूकतासँग जोड्नु पर्छ
- **खतरा विकास**: आक्रमणका नयाँ विधिहरूले वर्तमान सुरक्षाहरू बाइपास गर्न सक्छन्

## 🎯 आक्रमण परिस्थितिका उदाहरणहरू

Ghost ले सामान्य आक्रमण भेक्टरहरूलाई लक्षित गरे तापनि, विशिष्ट रोकथाम उचित कार्यान्वयन र परीक्षणमा निर्भर छ:

### WannaCry-शैली आक्रमणहरू
- **न्यूनीकरण**: `Set-Ghost -SMBv1` कमजोर प्रोटोकल असक्षम पार्छ
- **विचारहरू**: कुनै पनि पुराना सिस्टमलाई SMBv1 आवश्यक नपरेको सुनिश्चित गर्नुहोस्

### RDP-आधारित Ransomware
- **न्यूनीकरण**: `Set-Ghost -RDP` टाढाको डेस्कटप पहुँच ब्लक गर्छ
- **विचारहरू**: वैकल्पिक टाढाको पहुँच विधिहरू आवश्यक हुन सक्छ

### कागजात-आधारित मालवेयर
- **न्यूनीकरण**: `Set-Ghost -Macros` म्याक्रो कार्यान्वयन असक्षम पार्छ
- **विचारहरू**: वैध म्याक्रो-सक्षम कागजातहरूमा असर गर्न सक्छ

### USB-प्रसारित खतराहरू
- **न्यूनीकरण**: `Set-Ghost -USBStorage -AutoRun` USB कार्यक्षमता सीमित गर्छ
- **विचारहरू**: वैध USB उपकरण प्रयोगमा असर गर्न सक्छ

4. **स्टेकहोल्डर समीक्षा**: व्यापार एकाइहरूले परिवर्तनहरू अनुमोदन गर्छन् भनेर सुनिश्चित गर्नुहोस्

### तैनातीको समयमा
1. **चरणबद्ध दृष्टिकोण**: पहिले पायलट समूहहरूमा तैनात गर्नुहोस्
2. **प्रभाव निगरानी गर्नुहोस्**: प्रयोगकर्ता गुनासो वा सिस्टम समस्याहरूका लागि हेर्नुहोस्
3. **समस्याहरू कागजात गर्नुहोस्**: भविष्यको सन्दर्भका लागि कुनै पनि समस्याहरू रेकर्ड गर्नुहोस्
4. **परिवर्तनहरू सञ्चार गर्नुहोस्**: सुरक्षा सुधारहरूको बारेमा प्रयोगकर्ताहरूलाई जानकारी दिनुहोस्

### तैनातीपछि
1. **नियमित मूल्याङ्कन**: सेटिङहरू प्रमाणित गर्न आवधिक रूपमा `Get-Ghost` चलाउनुहोस्
2. **कागजात अद्यावधिक गर्नुहोस्**: वर्तमान सुरक्षा कन्फिगरेसनहरू कायम राख्नुहोस्
3. **प्रभावकारिता समीक्षा गर्नुहोस्**: सुरक्षा घटनाहरूका लागि निगरानी गर्नुहोस्
4. **निरन्तर सुधार**: खतरा परिदृश्यको आधारमा सेटिङहरू समायोजन गर्नुहोस्
